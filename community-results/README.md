# PolyCodeEval Community Results

Accepted self-evaluated submissions are stored under:

```text
pce-1.0/<level>/<github-user>/<submission-id>/
```

Each submission contains one `submission.json`, the unmodified evaluator output
below `evaluation/`, and optional public logs. Generated code is not accepted in
this directory. See [the submission guide](../docs/leaderboard/submitting-results.md)
for packaging, validation, ranking, and review rules.
